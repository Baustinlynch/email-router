Relay (SMTP) settings

The real SMTP account that delivers forwarded mail. For Zoho Mail: host smtp.zoho.com, port 587, STARTTLS on (or port 465 with SSL on), username = santa@brenden.zip, password = your Zoho password or an app-specific password (Zoho account → Security → App Passwords). Password changes are saved privately in .env, never shown or sent back to the browser.

Tests the saved settings, so save first: connects, starts TLS and logs in — no mail is sent.

Incoming mail (IMAP)

Poll a real mailbox for new mail and route it exactly like SMTP mail. For Zoho Mail: host imap.zoho.com, port 993, SSL on, mailbox INBOX. Set a separate mailbox account below, or use the relay credentials. Passwords are saved privately in .env and are never shown or sent back to the browser. Enable IMAP access in Zoho Mail first (Settings → Mail Accounts → IMAP).

Tests the saved settings, so save first: connects, logs in and opens the mailbox — no mail is read or changed.
